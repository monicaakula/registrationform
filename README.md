# Student Login & Registration Form

A simple **Student Registration Form** developed using HTML, CSS, and JavaScript. The form allows students to enter their personal details, select a course, and create a password.

## Features

* Student full name input
* Email address input
* 10-digit phone number input
* Course selection dropdown
* Password field
* Confirm password field
* Password visibility toggle
* Form validation
* Status message display
* Student data display after submission
* Responsive design

## Technologies Used

* **HTML5** – Creates the structure of the registration form
* **CSS3** – Provides styling and responsive layout
* **JavaScript** – Handles form validation and user interactions

## Courses Available

The registration form provides the following course options:

* Computer Science
* Information Technology
* Business Administration
* Engineering

## Form Fields

The registration form contains:

| Field            | Description                       |
| ---------------- | --------------------------------- |
| Full Name        | Enter the student's full name     |
| Email Address    | Enter a valid email address       |
| Phone Number     | Enter a 10-digit mobile number    |
| Select Course    | Choose a course from the dropdown |
| Password         | Create a password                 |
| Confirm Password | Re-enter the password             |

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `registrationform.html` in a web browser.
4. Enter the required student details.
5. Select a course.
6. Create and confirm the password.
7. Submit the form.

## Validation

JavaScript is used to validate the form data and display status messages.

The form can check:

* Empty fields
* Phone number format
* Email address
* Course selection
* Password requirements
* Password and confirm password matching

## Password Visibility

The form includes an eye icon that allows the user to show or hide the entered password.
